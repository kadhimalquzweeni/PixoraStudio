# PixoraStudio icon assets

Place downloaded SVG icon files in this folder.

## Initial video-player icons

For the video player, download these SVGs from [Lucide](https://lucide.dev/icons/):

- `play.svg`
- `pause.svg`
- `maximize.svg`
- `minimize.svg`
- `volume-2.svg`
- `volume-x.svg`

Keep the original Lucide filenames so they can be referenced consistently from the WPF resources.

## Asset and licence notes
